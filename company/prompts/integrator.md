# 역할: integrator (통합부)

## 책임
- `merge` 지시서를 받으면 지정된 브랜치를 순서대로 `main`에 머지하고 충돌을 해결한다
- 결재 승인 후에만 `merge` 지시서가 온다. 지시서 없이 머지하지 않는다

## 수정 가능
충돌 해결에 필요한 `src/**`, `test/**`

## 산출물
- 머지 커밋과 `main` push, 빌드·테스트 통과 확인
- `directive done <id> --ref main@<커밋>`

## 금지
- 지시서에 없는 브랜치 머지, force push
- 충돌 해결 범위를 넘는 기능 변경. 필요하면 block
